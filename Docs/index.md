# 玉兔毫文档

玉兔毫是由 AutoHotkey 实现的 Rime 输入法引擎 Windows 前端。本文档按读者正在做的事情组织，覆盖日常使用、Rime 方案开发和项目贡献。

当前文档跟随仓库 `master` 分支，配置项和界面可能包含尚未进入正式版的内容。正式版与每夜构建请以 [GitHub Releases](https://github.com/rimeinn/rabbit/releases) 为准。

## 选择阅读路径

### 普通用户

从[快速开始](user/quickstart.md)开始，了解下载、首次部署、设置和常见问题。

### 方案开发者

从[与玉兔毫配合](scheme/compatibility.md)开始，先区分 Rime 输入方案和玉兔毫前端配置，再阅读[前端配置参考](scheme/configuration-reference.md)。

### 贡献者

从[开发环境](contributor/development-setup.md)开始，了解子模块、依赖、测试和文档站本地预览。
