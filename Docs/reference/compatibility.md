# 兼容性

## Windows

玉兔毫保留旧版 Windows 的候选窗兼容路径。Windows 10 之前的系统会使用旧版候选窗；较新的系统默认使用现代候选窗，也可以在设置中主动选择旧版候选窗。

现代候选窗和旧版候选窗支持的外观字段不同。涉及阴影、横向流式、浮动预编辑和高级字体时，请查看具体页面的适用范围。

## 发行包架构

正式版和每夜构建通常提供 x86 与 x64 版本。编译版是单文件程序，但首次运行时仍可能向程序所在目录释放资源；请把它放在有写入权限的独立文件夹中。

## Rime 方案

玉兔毫使用 librime 作为输入法引擎。方案、词典和用户学习数据的兼容性由 Rime 配置及各方案自身决定；方案开发者应在玉兔毫和其他目标前端中分别测试。

当问题只在某个方案或某个目标程序出现时，提交反馈前请先用另一个内置或常见方案进行对照。
