# 术语表

| 术语 | 含义 |
| --- | --- |
| Rime | 输入法引擎，负责处理编码、词典和候选结果 |
| 前端 | 与操作系统和应用程序交互、显示候选窗的程序；玉兔毫和小狼毫都是 Rime 前端 |
| 输入方案 | 描述编码规则、翻译器和词典的 Rime 配置，通常以 `schema.yaml` 为核心 |
| 配色方案 | 候选窗颜色集合，位于 `preset_color_schemes` |
| 部署 | 将 YAML 配置和词典编译为 Rime 可加载的运行数据 |
| 用户文件夹 | 保存自定义配置、方案覆盖、词典和学习数据的目录 |
| 候选窗 | 显示候选文字、序号、注释和预编辑内容的窗口 |
| 预编辑 | 用户尚未提交的编码或候选预览 |
| 现代候选窗 | 基于 Direct2D／WIC 的新候选窗后端 |
| 旧版候选窗 | 面向旧版 Windows 的兼容候选窗后端 |
| nightly | 从 `master` 或 `dev` 分支自动生成的预发布程序包 |
