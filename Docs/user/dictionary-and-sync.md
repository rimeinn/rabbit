# 用户词典与同步

玉兔毫的“用户词典”页面和托盘菜单中的“用户词典管理”都可以管理 Rime 用户词典。先在列表中选中一个词典，
再执行备份、恢复、导入或导出操作。

## 词典快照

词典快照用于在不同的 Rime 系统之间迁移输入习惯：

1. 选择要迁移的用户词典；
2. 点击“输出词典快照”；
3. 将生成的 `.userdb.txt` 文件复制到另一台电脑；
4. 在另一台电脑的用户词典管理中点击“合入词典快照”，选择该文件。

输出的快照会放在 Rime 用户资料的同步目录中。恢复操作是合入词条，不是用一个空白词典覆盖全部用户资料。
在升级或迁移前仍建议额外备份整个用户文件夹。

如果快照来自其他 Rime 前端，只要文件格式受当前 Rime 支持，也可以使用“合入词典快照”。遇到失败时，先确认
目标词典已经存在，并检查同步目录是否可写。

## 文本码表

“导出文本码表”适合方案开发者查看和整理使用期间新增的词组。玉兔毫会将选定词典中的记录导出为文本文件，
并报告导出的记录数。

“导入文本码表”适合将外部词库整理成 Rime 词典使用的 TSV 文本格式后导入。导入前建议：

- 先输出一次词典快照；
- 检查编码、分隔符和词条字段；
- 确认导入目标词典没有选错；
- 导入后在实际方案中测试编码和候选顺序。

在 Rime 前端之间迁移已有输入习惯时，优先使用词典快照，而不是把用户词典当作普通文本码表处理。

## 用户资料同步

“维护与同步”页面的“同步用户资料”调用 Rime 的用户资料同步功能，会合并本机和同步目录中的数据。它适合
已经配置好 Rime 同步目录的环境；同步目录不可访问或同时有其他维护操作时，操作可能失败。

同步前后都可以从托盘菜单打开“用户文件夹”，确认配置和词典文件是否符合预期。同步功能不是云存储服务，仍需由
用户自行提供可用的同步目录及备份策略。

## 选择哪种方式

| 目标 | 推荐方式 |
| --- | --- |
| 迁移整本用户词典和输入习惯 | 词典快照 |
| 查看、筛选或编辑新增词条 | 导出文本码表 |
| 将外部 TSV 词库导入已有词典 | 导入文本码表 |
| 在同一套 Rime 用户资料之间保持同步 | 用户资料同步 |
| 迁移全部配置、方案和学习数据 | 复制整个 Rime 用户文件夹 |
