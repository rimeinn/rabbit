# 文件与目录

玉兔毫把随程序发布的共享数据、用户自定义资料和运行日志分开保存。需要排查问题或迁移环境时，先从托盘菜单
打开对应目录，不要凭文件名猜测实际位置。

## 主要目录

| 路径 | 用途 | 是否建议手动修改 |
| --- | --- | --- |
| `Data/` | 随程序发布的 Rime 共享数据、内置方案和预设配置 | 通常不修改；个人配置放到用户目录 |
| `Rime/` | 默认的 Rime 用户目录，保存自定义配置、用户词典和学习数据 | 可以通过 Rime 配置或玉兔毫功能修改 |
| `Rime/build/` | Rime 部署后生成的运行配置 | 不直接编辑；通过重新部署生成 |
| `%TEMP%\rime.rabbit\` | 玉兔毫日志目录 | 可以复制日志用于反馈，不要随意删除正在使用的日志 |
| 程序目录 | Rabbit 脚本、DLL、图标和编译版释放的资源 | 不要把个人配置误放在这里 |

## 用户目录如何确定

玉兔毫按以下顺序确定 Rime 用户目录：

1. 程序目录存在 `.portable` 文件时，使用程序目录下的 `Rime`；
2. 否则读取注册表 `HKCU\Software\Rime\Rabbit` 的 `RimeUserDir` 值；
3. 如果没有有效的注册表设置，回退到程序目录下的 `Rime`。

因此，便携版和没有额外注册表配置的源码运行通常都能在程序目录旁找到 `Rime/`。通过托盘菜单打开“用户文件夹”
可以确认当前真正生效的目录。

## 常见文件

| 文件 | 作用 |
| --- | --- |
| `rabbit.custom.yaml` | 玉兔毫前端的界面和行为设置 |
| `default.custom.yaml` | Rime 通用设置、方案列表和方案选单设置 |
| `<方案标识>.custom.yaml` | 某个输入方案的覆盖设置 |
| `user.yaml` | Rime 用户状态和用户资料配置 |
| `build/` 下的 YAML | 部署生成的运行配置，不作为手动编辑入口 |

手动修改 YAML 后，需要重新部署。编辑前保留原有的 `patch` 结构，并确保缩进、冒号和字符串引号正确。

## 备份和清理

若要完整迁移环境，请先退出玉兔毫，再复制整个用户目录。只迁移输入习惯时，使用[词典快照](dictionary-and-sync.md)通常
更安全。日志问题可以直接从托盘菜单打开日志目录；清理日志前应先退出正在运行的玉兔毫实例。

编译版首次运行时会把内置资源释放到程序目录，因此请将 EXE 放在有写入权限的独立文件夹中。资源释放不等于覆盖
用户目录；用户配置仍由 Rime 用户目录位置决定。
