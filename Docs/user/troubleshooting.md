# 故障排除

## 完全无法输入

- 确认玉兔毫仍在通知区域运行，并检查托盘菜单中的启用／禁用状态；
- 确认当前窗口不是密码输入框，或没有被 `bypass_password_fields` 绕过；
- 检查是否误触暂停快捷键；
- 在其他普通文本编辑器中测试，以排除目标程序自身的输入限制。

## 没有候选窗

- 先尝试重新部署；
- 确认至少有一个输入方案处于启用状态；
- 检查 `rabbit.custom.yaml` 的 YAML 格式和最近改动；
- 如果使用旧版 Windows，候选窗会自动采用旧版后端，部分现代外观设置不会生效。

## 方案或词典没有生效

Rime 修改后需要重新部署。若方案仍不出现：

1. 打开控制面板的“输入方案与选单”；
2. 确认方案已经安装并勾选；
3. 点击“应用并重新部署”；
4. 重新打开目标程序后再测试。

## 窗口位置或字体异常

记录 Windows 缩放比例、显示器数量、候选窗布局和字体设置。可以先恢复默认配色、字体和布局，再逐项启用自定义项。

## 提交问题时提供什么

请尽量附上：

- Windows 版本、玉兔毫版本和 x86／x64 发行包类型；
- 使用的 Rime 输入方案；
- 可复现步骤和目标程序；
- 候选窗布局及相关 `rabbit.custom.yaml` 内容；
- 截图、错误信息和日志目录中的相关文件。

程序漏洞请提交到 [Issues](https://github.com/rimeinn/rabbit/issues)，使用和配置问题可以发到 [Discussions](https://github.com/rimeinn/rabbit/discussions)。
